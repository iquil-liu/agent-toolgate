# 超时与取消

本文是离线知识检索演示使用的自造技术说明，讨论通用实现与验证方法。主题术语：截止时间、取消令牌、连接超时、资源释放、超时预算。所有场景均为抽象示例，不关联任何真实组织或运行环境。

## 预算传递

任务截止时间传递到每个子调用，子调用不能重新获得完整超时预算。连接超时和读取超时分别控制建立通道与等待响应。串行步骤执行前检查剩余时间，预算不足时应立即停止派发。

## 取消传播

取消令牌向下游传播，循环和阻塞等待应定期检查取消状态。客户端停止等待不代表服务端写入已经撤销。对于状态不明的写入，先记录操作标识，再通过回读判断实际结果。

## 资源回收

无论成功、失败还是取消，都应关闭文件、游标和连接。取消清理本身也要有时间上限，防止退出过程无限等待。测试需要覆盖取消发生在调用前、处理中和完成后的不同边界。
