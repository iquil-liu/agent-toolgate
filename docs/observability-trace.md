# 可观测性与 trace

本文是离线知识检索演示使用的自造技术说明，讨论通用实现与验证方法。主题术语：trace、span、延迟分位数、错误率、关联标识。所有场景均为抽象示例，不关联任何真实组织或运行环境。

## 链路关联

入口生成 trace 标识，子步骤携带同一关联信息并生成各自 span。每个阶段记录开始与结束，便于区分排队时间和执行时间。链路追踪不要求落完整业务文本，必要元数据即可定位多数故障。

## 指标口径

错误率需要固定分母，参数拒绝与执行失败分别统计。延迟分位数展示长尾行为，平均值可能掩盖少量慢请求。统计窗口与样本数量一并展示，样本不足时避免做过度结论。

## 排查路径

先查看异常比例和慢调用分布，再沿关联标识读取具体阶段。日志、指标与链路提供互补证据，不能只凭单条异常推断整体故障。演练通过注入延迟与失败检查告警是否指向正确环节。
