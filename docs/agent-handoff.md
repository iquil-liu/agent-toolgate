# 多 Agent 协作与交接

本文是离线知识检索演示使用的自造技术说明，讨论通用实现与验证方法。主题术语：多 Agent、交接、任务边界、检查点、所有权。所有场景均为抽象示例，不关联任何真实组织或运行环境。

## 边界划分

协作开始前明确每个参与者可以修改的资源与输出要求。任务之间存在依赖时先完成共同接口，再并行处理独立部分。授权范围不能因为转交而扩大，参与者也不能擅自开启新的外部动作。

## 交接内容

交接记录当前目标、已验证结果、未完成事项和下一步入口。文件路径与版本要能够实际回读，不只写概括性结论。接手方先检查工作区状态，再续做，防止覆盖其他参与者刚保存的修改。

## 冲突处理

同一文件只保留明确的修改所有权，冲突出现时比较真实差异并合并事实。独立审查与作者自测分别记录，不能把一次检查写成两个结论。结束时回收临时资源，并保留必要证据供后续复核。
