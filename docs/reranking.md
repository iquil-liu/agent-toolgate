# 重排模型与 score_detail

本文是离线知识检索演示使用的自造技术说明，讨论通用实现与验证方法。主题术语：重排、标题命中、词项覆盖率、score_detail、候选集。所有场景均为抽象示例，不关联任何真实组织或运行环境。

## 召回边界

重排只调整已经召回的候选，无法找回从未进入候选集的文档。候选数量增加会带来更高计算开销，也可能加入更多噪声。离线基线使用透明规则，便于验证每个候选为什么靠前。

## 特征与分数

标题命中衡量查询词出现在标题路径中的比例，词项覆盖率衡量标题和正文共同覆盖的比例。最终分由 RRF 融合分加两项固定权重组成。score_detail 同时保留原始排名、相似度与各项贡献。

## 稳定性验证

重复查询应该返回一致顺序，同分时按文档标识与块序号排序。测试不仅检查第一条结果，也复算最终分，防止解释字段与实际排序脱节。生产模型替换前需比较质量、延迟和可解释程度。
