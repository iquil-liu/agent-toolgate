# 冲突规则与单一真源

本文是离线知识检索演示使用的自造技术说明，讨论通用实现与验证方法。主题术语：单一真源、版本、冲突规则、优先级、证据。所有场景均为抽象示例，不关联任何真实组织或运行环境。

## 来源确定

配置和任务状态需要明确的单一真源，其他副本只作为缓存或展示。读取缓存时附上版本，写入时检查预期版本，防止旧内容覆盖新状态。不同字段可以有不同来源，但归属必须清楚。

## 规则优先级

冲突规则依据授权范围、当前指令和最新证据确定优先级。历史摘要不能推翻实际文件，临时备注也不能自动改变硬性约束。发现矛盾时先核对事实，不能通过重复保存把争议消除。

## 变更验证

每次写入后回读关键状态，确认版本和内容符合预期。并发修改失败时重新读取并合并，不只更新版本号强行重试。测试模拟两个写入者竞争，验证冲突可见且已有修改不会被静默丢弃。
