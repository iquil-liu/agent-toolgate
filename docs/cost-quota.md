# 成本控制与配额

本文是离线知识检索演示使用的自造技术说明，讨论通用实现与验证方法。主题术语：token、配额、预算、单价、成本估算。所有场景均为抽象示例，不关联任何真实组织或运行环境。

## 预算模型

任务开始前估算输入与输出 token，结合可配置单价得到预期成本。单价带版本和计费单位，避免把每千与每百万单位混用。估算值用于决策，实际结算仍以真实用量为依据。

## 配额执行

配额同时限制单次任务和时间窗口总量，并为并发任务预留额度。达到阈值后降低上下文长度或停止后续步骤。重试和失败调用也可能产生成本，因此不能只统计最终成功请求。

## 优化验证

缓存、批处理和选择较小模型都需要比较质量与成本。报告同时显示总成本、单任务成本和失败浪费，避免把请求量减少误认为效率提升。占位单价必须明确标注，不能作为真实账单结论。
