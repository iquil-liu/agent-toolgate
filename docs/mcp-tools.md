# MCP 协议与工具注册

本文是离线知识检索演示使用的自造技术说明，讨论通用实现与验证方法。主题术语：MCP、JSON-RPC、stdio、工具注册、能力协商。所有场景均为抽象示例，不关联任何真实组织或运行环境。

## 连接与能力协商

客户端建立标准输入输出通道后先发送初始化请求，服务端返回协议版本和可用能力。每条消息占据一行，诊断信息写入错误流，避免污染协议消息。请求标识用于关联响应，通知消息没有响应。

## 工具发现与版本

工具注册表保存名称、版本、描述和参数契约。工具列表仅暴露声明，不序列化处理函数。调用方先发现能力再选择工具，弃用版本可以保留声明，但调用时应返回明确的结构化错误。

## 调用隔离与验证

服务端在执行处理函数前校验参数，失败时返回稳定错误码。调用结束记录耗时与入参摘要，便于定位协议层和业务层的边界。测试需要覆盖未知方法、非法参数和坏消息后的通道恢复。
