# 向量检索与 ANN

本文是离线知识检索演示使用的自造技术说明，讨论通用实现与验证方法。主题术语：向量检索、ANN、余弦相似度、归一化、embedding。所有场景均为抽象示例，不关联任何真实组织或运行环境。

## 离线表示

字符二元组和三元组经稳定哈希映射到固定维度，词频与逆文档频率提供权重。向量归一化后点积等于余弦相似度。相同输入与相同语料统计必须得到一致结果，不依赖进程随机种子。

## 搜索取舍

小语料可以逐块计算相似度，复杂度随块数线性增长。ANN 使用近似索引降低大规模搜索耗时，但需要额外的存储和召回验证。离线哈希向量存在碰撞，不能宣称具有完整语义理解能力。

## 更新一致性

新增内容会影响逆文档频率，全局权重与查询表示必须使用同一版本。保存原始特征计数便于刷新权重，而不重新解析未变文档。测试检查向量维度、单位范数、空输入与跨进程确定性。
