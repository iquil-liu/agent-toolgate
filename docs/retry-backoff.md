# 失败重试与退避

本文是离线知识检索演示使用的自造技术说明，讨论通用实现与验证方法。主题术语：指数退避、随机抖动、重试预算、限流、瞬时错误。所有场景均为抽象示例，不关联任何真实组织或运行环境。

## 错误分类

瞬时网络错误和短期限流可以重试，参数非法与权限拒绝通常需要先修复原因。调用方应保留原始错误分类，不能把所有失败统一重试。写入操作在重试前必须确认幂等能力或查询已有结果。

## 等待策略

指数退避逐次增加等待时间，随机抖动避免大量请求同时恢复。服务端提供等待提示时应优先遵守，但总等待仍受任务截止时间约束。退避上限用于防止长时间占用执行资源与连接。

## 停止条件

重试预算同时限制次数和累计时间，达到边界后返回可诊断的失败。指标区分首次成功、重试成功和最终失败。测试使用可控时钟验证等待序列，避免真实等待导致测试缓慢和偶发失败。
