# Agent 编排与 Workflow

本文是离线知识检索演示使用的自造技术说明，讨论通用实现与验证方法。主题术语：Agent、Workflow、状态机、检查点、补偿。所有场景均为抽象示例，不关联任何真实组织或运行环境。

## 状态与步骤

编排器把目标拆成可恢复步骤，每一步声明输入、输出和完成条件。状态机限制合法迁移，避免失败后直接进入成功状态。步骤执行前读取检查点，完成后保存结果引用，便于中断后继续。

## 分支与补偿

条件分支依据可验证的数据选择路径，不依赖模糊描述。外部写入应提供幂等标识，跨步骤无法原子提交时使用补偿动作。补偿也可能失败，因此要记录待处理状态并允许人工接管。

## 回放与验收

回放使用固定工具返回值检查路径选择，不重复真实副作用。验收同时观察最终结果和中间门禁，确认没有跳过授权步骤。长流程应限制最大步数，并在预算耗尽时返回可继续的上下文。
