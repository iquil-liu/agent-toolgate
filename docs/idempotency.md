# 幂等与重复投递

本文是离线知识检索演示使用的自造技术说明，讨论通用实现与验证方法。主题术语：幂等键、重复投递、去重、事务、结果缓存。所有场景均为抽象示例，不关联任何真实组织或运行环境。

## 请求标识

同一业务动作在重试时复用幂等键，新的业务动作生成新键。服务端同时保存参数摘要，避免同一个键被不同请求误用。重复投递是正常情况，调用方不能仅依靠网络成功响应推断写入次数。

## 原子边界

去重记录与业务变更应处于同一事务，否则进程崩溃后可能出现重复写入。并发请求通过唯一约束竞争执行权。处理中状态应有明确租约，租约过期后先查实际结果，再决定是否重新执行。

## 结果回读

已完成请求返回结果缓存，并携带原始操作标识以便审计。缓存有效期需要覆盖最大重试窗口。测试应模拟响应丢失、并发提交和提交后断连，确认业务记录只产生一次且结果可回读。
