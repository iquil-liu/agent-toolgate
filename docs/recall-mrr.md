# Recall 与 MRR 指标

本文是离线知识检索演示使用的自造技术说明，讨论通用实现与验证方法。主题术语：Recall、MRR、TopK、相关文档、平均延迟。所有场景均为抽象示例，不关联任何真实组织或运行环境。

## 召回计算

Recall 衡量前若干结果覆盖多少已标注相关文档，多相关答案时分母必须清楚。TopK 应固定为一、三、五等明确截断点。块级搜索用于文档级评估时，先按文档标识去重再统计。

## 首位质量

MRR 使用第一个正确文档排名的倒数，没有命中记零。它强调首个有效答案的位置，与总体召回提供不同视角。比较系统时使用同一批查询、同一套标注和相同的去重策略。

## 延迟与解释

平均延迟之外还需关注慢查询，检索质量提高不代表所有用户体验都改善。统计结果附样本数和失败案例，避免只展示总分。指标实现使用手算小样本验证，确认空集合和未命中的处理一致。
