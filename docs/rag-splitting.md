# RAG 文档切分策略

本文是离线知识检索演示使用的自造技术说明，讨论通用实现与验证方法。主题术语：RAG、标题层级、段落、块大小、元数据。所有场景均为抽象示例，不关联任何真实组织或运行环境。

## 结构优先

文档切分先识别标题层级，为每个正文块保留标题路径。章节边界不能被固定长度窗口随意跨越，否则检索结果难以解释。空章节不产生正文块，代码围栏中的井号也不应被识别为标题。

## 长度边界

单块最多六百字符，超长章节先按段落拆分，再对超长单段落做硬切分。边界按字符计算而不是编码字节，避免中文内容被截断。块索引在文档内递增，用于定位与稳定排序。

## 质量验证

文档标识、标题路径和块序号一起构成来源信息。调整块大小时比较召回率与上下文噪声，不只观察块数变化。测试覆盖恰好上限、连续长段、嵌套标题和没有标题的前言，检查内容不丢失。
