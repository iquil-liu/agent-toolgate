# 上下文管理与记忆

本文是离线知识检索演示使用的自造技术说明，讨论通用实现与验证方法。主题术语：上下文窗口、短期记忆、长期记忆、摘要、来源。所有场景均为抽象示例，不关联任何真实组织或运行环境。

## 信息分层

短期记忆保存当前步骤必需的信息，长期记忆保存稳定偏好和已经确认的结论。上下文窗口有限时优先保留当前目标、约束和未解决问题。历史摘要需要来源，不能把推测写成已确认事实。

## 压缩与恢复

压缩时保存关键实体、决策理由和下一步入口，删除重复工具输出。恢复任务先核对当前文件和实际状态，防止旧摘要覆盖新修改。不同来源发生冲突时应比较时间与证据，而不是简单拼接。

## 遗忘与隔离

记忆需要有效期和任务范围，临时错误不应永久影响后续判断。敏感输入只保留必要摘要，不把原文放入公共知识库。验证记忆质量可以设置跨会话恢复用例，检查约束是否继续生效。
