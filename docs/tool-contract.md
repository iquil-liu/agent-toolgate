# 工具契约校验

本文是离线知识检索演示使用的自造技术说明，讨论通用实现与验证方法。主题术语：JSON Schema、类型校验、必填字段、枚举、结构化错误。所有场景均为抽象示例，不关联任何真实组织或运行环境。

## 输入边界

工具契约描述允许的类型、必填字段和取值范围。布尔值与整数要明确区分，空字符串也不等同于缺失字段。嵌套对象的错误路径应定位到具体字段，让调用方能直接修正参数。

## 声明与执行

注册时检查契约结构，调用时校验实际输入。枚举、长度和正则约束应在处理函数之前执行，避免产生部分副作用。返回值需要可序列化，异常信息经过清理后才进入公共响应。

## 兼容性测试

新增必填字段会影响旧调用方，版本升级应明确兼容范围。测试覆盖合法输入、类型错误、越界和嵌套路径，不只检查单个成功样例。契约与实现不一致时，应先确定真实业务语义再修复。
