# 评测集构建

本文是离线知识检索演示使用的自造技术说明，讨论通用实现与验证方法。主题术语：评测集、标注、困难负例、数据泄漏、查询分层。所有场景均为抽象示例，不关联任何真实组织或运行环境。

## 样本设计

评测集按真实任务类别组织，包含术语查询、简短提问、符号输入和没有答案的请求。每条样本标注可接受的文档标识与理由。覆盖多个主题比重复同一标题更能反映实际检索能力。

## 标注质量

标注者依据正文证据确定相关性，不因为标题相似就直接认定正确。困难负例选择共享术语但回答不同问题的文档。标注存在争议时保留说明，避免通过任意扩大正确集合掩盖错误。

## 实验隔离

调整参数使用开发样本，最终比较使用独立留出样本，减少数据泄漏。实验记录语料版本、参数和执行时间。失败分析先定位召回、融合或重排环节，再修改对应实现并重新验证。
