# 权限与最小授权

本文是离线知识检索演示使用的自造技术说明，讨论通用实现与验证方法。主题术语：最小授权、权限范围、资源隔离、授权门禁、拒绝策略。所有场景均为抽象示例，不关联任何真实组织或运行环境。

## 权限建模

权限声明同时限制动作、资源和有效时间。只读能力不应隐含写入权限，单个任务的授权也不应自动扩展到其他资源。工具执行前检查当前身份与目标资源，缺失授权时返回明确拒绝。

## 门禁位置

授权门禁位于实际副作用之前，并使用最新状态判断。展示草稿与发布内容是两个不同动作，调用方需要准确表达意图。长任务恢复后重新检查临时授权，避免使用已经过期的能力。

## 隔离验证

测试用不同权限身份访问相同资源，确认允许与拒绝路径都符合规则。审计记录授权判断的结果，但不落访问令牌。默认拒绝策略需要可解释原因，方便排查配置错误而不是扩大权限。
