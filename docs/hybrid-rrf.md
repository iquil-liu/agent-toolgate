# 混合检索与 RRF

本文是离线知识检索演示使用的自造技术说明，讨论通用实现与验证方法。主题术语：混合检索、RRF、FTS5、倒排索引、候选融合。所有场景均为抽象示例，不关联任何真实组织或运行环境。

## 两路召回

全文通道擅长精确术语，向量通道补充字符近似匹配。混合检索先独立获取候选与排名，再融合两路证据。中文全文索引显式加入字符片段，使不带空格的标题也能被字面查询命中。

## RRF 融合

RRF 对每个候选累加一除以六十加排名，排名从一开始。两路都命中的块通常得到更高融合分，单路缺失不虚构贡献。保留全文排名与向量排名，为后续重排提供可核对的基础。

## 重排解释

混合检索之后使用标题命中与词项覆盖率重排。输出分别展示融合分、标题加分和覆盖率加分，最终分可以手动复算。特殊字符查询先提取字面词项，避免全文语法符号导致检索异常。
